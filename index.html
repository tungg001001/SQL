SQL Injection（SQL 注入攻擊）完整教學與案例解析

本教學導覽詳細說明 SQL 注入攻擊的核心原理、常見類型、實際程式碼範例與防禦手法，協助建立安全的網頁應用程式開發思維。

1. 身分驗證繞過（Classic Login Bypass）

成因：動態字串拼接

當後端程式將使用者輸入未經過濾即直接拼接到 SQL 語法中時，攻擊者可輸入單引號 ' 中斷字串，並插入 OR '1'='1 等恆真條件，破壞原有邏輯。

❌ 不安全的後端程式碼 (PHP / Dynamic) 
$sql = "SELECT * FROM users 
        WHERE username = '" . $_POST['user'] . "' 
        AND password = '" . $_POST['pass'] . "'";
⚠️ 攻擊者輸入與最終 SQL 語法

Payload: admin' -- 或 ' OR '1'='1

SELECT * FROM users 
WHERE username = '' OR '1'='1' AND password = 'xxx'

2. 聯合查詢注入（UNION-Based Injection）

目標：跨表撈取敏感資料

攻擊者利用 UNION SELECT 結合原本的查詢，以擴充回傳的結果集。核心條件： 兩側查詢必須具備相同的欄位數量，且對應欄位的資料型態必須相容。

範例：利用 UNION 撈取其他資料表的密碼 Hash

輸入 Payload：' UNION SELECT id, username, password FROM users --

SELECT id, title, content FROM articles WHERE id = -1 
UNION SELECT id, username, password FROM users --

3. 盲注與時間延遲（Blind & Time-Based SQLi）

情境：無畫面直接回傳資料

布林盲注 (Boolean-Based)

根據頁面回應為「True (正常)」或「False (錯誤/空)」推斷資料內容。

' AND SUBSTRING(username, 1, 1) = 'a' --

時間盲注 (Time-Based)

藉由資料庫函數引起回應延遲（如 SLEEP(3)）來判定條件是否成立。

' AND IF(1=1, SLEEP(3), 0) --

4. ORDER BY 防禦陷阱與白名單機制

特例防禦

傳統參數化查詢（Prepared Statements）將輸入綁定為 Literal Value，因此**無法直接用於 SQL 的 ORDER BY 欄位名稱**。遇到此類動態排序需求，必須改用後端「白名單（Whitelist）」比對進行防禦。

✅ 安全寫法：白名單過濾範例 (Node.js/Express)
const allowedSortColumns = ['id', 'username', 'created_at'];
const sortBy = allowedSortColumns.includes(req.query.sort) ? req.query.sort : 'id';
const sql = `SELECT * FROM users ORDER BY ${sortBy} ASC`;

主流語言安全防禦範例 (Prepared Statements)

以下範例展示如何在各開發語言中使用參數化查詢阻絕 SQL Injection。

使用 sqlite3 或 psycopg2，將變數以 Tuple 傳遞至 execute()：

# ✅ 安全：參數化綁定
cursor.execute("SELECT * FROM users WHERE username = ? AND password = ?", (username, password))
user = cursor.fetchone()

使用 mysql2 或 pg 套件：

// ✅ 安全：使用 execute 方法與預處理陣列
const [rows] = await connection.execute(
  'SELECT * FROM users WHERE username = ? AND password = ?',
  [userInputUsername, userInputPassword]
);

使用 PDO 預處理指令：

<?php
// ✅ 安全：PDO prepare 與 execute
$stmt = $pdo->prepare('SELECT * FROM users WHERE username = :user AND password = :pass');
$stmt->execute(['user' => $userInputUsername, 'pass' => $userInputPassword]);
$user = $stmt->fetch();
?>

使用 JDBC PreparedStatement：

// ✅ 安全：JDBC 綁定變數
String sql = "SELECT * FROM users WHERE username = ? AND password = ?";
PreparedStatement stmt = connection.prepareStatement(sql);
stmt.setString(1, userInputUsername);
stmt.setString(2, userInputPassword);
ResultSet rs = stmt.executeQuery();
